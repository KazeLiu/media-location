## 一、功能概述

在现有媒体经纬度工作台中添加电子围栏管理功能，支持用户创建、编辑、删除多边形围栏区域，并通过拖拽照片到围栏列表快速设置随机坐标。

### 核心功能

1. **围栏管理标签页**：在左侧面板新增"电子围栏"标签，提供围栏列表的增删改查
2. **地图多边形绘制**：点击围栏列表项，在地图上绘制/编辑多边形区域
3. **开关控制**：围栏标签页有全局开关，开启后在"基本功能"标签页左侧显示悬浮围栏列表
4. **照片快速定位**：
   - 拖拽照片到围栏列表项 → 自动设置到该围栏内随机坐标，地图跳转到该位置
   - 拖拽照片到地图 → 保持原有精确定位行为（不受围栏影响）

## 二、需求明细

### 2.1 围栏数据结构

每个围栏包含以下属性：

- **ID**：唯一标识符（UUID）
- **名称**：用户自定义名称（必填）
- **颜色**：十六进制颜色值（如 `#FF5733`），用于地图显示区分
- **顶点坐标**：多边形顶点数组，存储 WGS-84 坐标
- **创建时间**：ISO 8601 格式时间戳
- **更新时间**：ISO 8601 格式时间戳

### 2.2 围栏管理（标签页）

#### 2.2.1 列表显示

- 以卡片形式展示所有围栏
- 每张卡片显示：围栏名称、颜色色块、操作按钮
- 支持滚动查看

#### 2.2.2 新建围栏

1. 点击"新建围栏"按钮
2. 弹出对话框，输入围栏名称和选择颜色
3. 确认后进入地图绘制模式
4. 用户在地图上点击多个点形成多边形
5. 双击或点击"完成"按钮结束绘制
6. 保存围栏数据到后端

#### 2.2.3 编辑围栏

1. 点击围栏卡片的"编辑"按钮
2. 可以修改围栏名称和颜色
3. 点击"编辑区域"按钮进入地图编辑模式
4. 在地图上拖动顶点调整形状，支持添加/删除顶点
5. 保存修改

#### 2.2.4 删除围栏

1. 点击围栏卡片的"删除"按钮
2. 弹出确认对话框
3. 确认后删除围栏数据

#### 2.2.5 查看围栏

- 点击围栏卡片（非按钮区域）在地图上高亮显示该围栏区域
- 地图自动缩放以完整显示该围栏

#### 2.2.6 全局开关

- 标签页顶部有一个开关："在基本功能显示围栏列表"
- 开启后，切换到"基本功能"标签时，地图左侧显示悬浮围栏列表
- 开关状态持久化保存

### 2.3 地图绘制与编辑

#### 2.3.1 高德地图实现（主要）

- 使用高德 JS API 的 `AMap.PolygonEditor` 进行多边形绘制和编辑
- 绘制模式：用户点击地图添加顶点，双击或点击"完成"按钮结束
- 编辑模式：顶点可拖动调整位置，支持中点添加新顶点，点击顶点删除
- 围栏区域使用半透明填充，边框使用围栏颜色
- 同时只能有一个围栏处于编辑状态

#### 2.3.2 Mapbox 实现（兼容）

- 安装 `@mapbox/mapbox-gl-draw` 插件
- 使用其多边形绘制功能
- 保持与高德一致的交互体验

#### 2.3.3 坐标系处理

- **存储**：围栏顶点统一使用 WGS-84 坐标存储
- **高德显示**：从 WGS-84 转换为 GCJ-02 后在地图上绘制
- **Mapbox 显示**：直接使用 WGS-84 坐标
- **照片设置**：随机坐标生成后统一使用 WGS-84 写入 XMP

### 2.4 悬浮围栏列表

#### 2.4.1 显示条件

- 当围栏开关开启时，在"基本功能"标签页显示
- 固定在地图左侧（不可拖拽）
- 宽度约 200px，垂直居中

#### 2.4.2 列表样式

- 白色/半透明背景卡片
- 列表项只显示围栏名称 + 颜色色块
- 支持滚动查看
- 鼠标悬停时高亮，提示"拖拽照片到此处"

#### 2.4.3 拖拽交互

1. 用户从媒体列表拖拽照片
2. 悬停在悬浮列表的围栏项上时，该项高亮
3. 松开鼠标完成拖放
4. 自动计算该围栏内的随机坐标（WGS-84）
5. 调用照片定位接口，设置坐标
6. 地图自动跳转到该坐标位置并高亮显示
7. 显示成功提示："已设置到围栏 XXX 内的随机位置"

### 2.5 随机坐标生成算法

采用**三角剖分 + 重心坐标法**，确保坐标均匀分布在多边形内部：

1. 将多边形顶点进行三角剖分（Delaunay 或 Earcut）
2. 按三角形面积加权随机选择一个三角形
3. 在该三角形内使用重心坐标随机生成一个点
4. 返回该点的经纬度坐标

## 三、数据持久化

### 3.1 存储位置

- 文件路径：`data/geofences.json`
- 与 `data/app.config.json` 并列

### 3.2 数据格式

```json
{
  "enabled": false,
  "geofences": [
    {
      "id": "uuid-v4",
      "name": "公园区域",
      "color": "#FF5733",
      "coordinates": [
        { "longitude": 116.397428, "latitude": 39.90923 },
        { "longitude": 116.398428, "latitude": 39.90923 },
        { "longitude": 116.398428, "latitude": 39.91023 },
        { "longitude": 116.397428, "latitude": 39.91023 }
      ],
      "createdAt": "2026-06-14T10:00:00.000Z",
      "updatedAt": "2026-06-14T10:00:00.000Z"
    }
  ]
}
```

### 3.3 初始状态

如果文件不存在，服务端自动创建空配置：

```json
{
  "enabled": false,
  "geofences": []
}
```

## 四、后端 API 设计

### 4.1 获取围栏配置

**接口**：`GET /api/geofences`

**响应**：
```json
{
  "enabled": false,
  "geofences": [...]
}
```

### 4.2 保存围栏配置

**接口**：`POST /api/geofences`

**请求体**：
```json
{
  "enabled": true,
  "geofences": [...]
}
```

**响应**：
```json
{
  "enabled": true,
  "geofences": [...]
}
```

### 4.3 错误处理

- 文件读写失败：返回 500 错误并记录到操作日志
- 数据格式错误：返回 400 错误
- 并发写入：使用文件锁或原子写入（写临时文件 + 重命名）

## 五、前端组件设计

### 5.1 新增组件

#### GeofenceTab.vue
- 围栏管理标签页主组件
- 包含围栏列表、新建/编辑/删除按钮、全局开关
- 与 `App.vue` 的 `geofenceModel` 交互

#### GeofenceFloatingList.vue
- 悬浮围栏列表组件
- 接收围栏数据和拖拽事件
- 发射 `drop-to-geofence` 事件给父组件

#### GeofenceEditorDialog.vue
- 围栏编辑对话框
- 输入围栏名称和选择颜色
- 提供"编辑区域"按钮触发地图绘制

### 5.2 修改组件

#### App.vue
- 新增 `geofenceModel` 响应式状态
- 管理围栏数据加载和保存
- 处理 `drop-to-geofence` 事件，调用随机坐标生成和照片定位

#### LeftPanel.vue
- 新增"电子围栏"标签页
- 渲染 `GeofenceTab` 组件

#### MapPanel.vue
- 扩展 props：`geofences`、`editingGeofenceId`、`drawingMode`
- 将围栏数据传递给 `AmapPanel` 和 `MapboxPanel`
- 发射围栏编辑相关事件

#### AmapPanel.vue
- 新增围栏绘制和编辑逻辑
- 使用 `AMap.PolygonEditor`
- 渲染所有围栏多边形
- 处理绘制模式和编辑模式切换

#### MapboxPanel.vue
- 集成 `@mapbox/mapbox-gl-draw`
- 保持与高德一致的交互逻辑

### 5.3 工具函数

#### lib/geofenceEditor.ts
- 围栏编辑器适配层
- 提供统一接口：`createPolygon()`, `editPolygon()`, `deletePolygon()`
- 内部根据地图类型调用对应实现

#### lib/geofenceUtils.ts
- 随机坐标生成：`getRandomPointInPolygon(coordinates)`
- 多边形面积计算、三角剖分等工具函数
- 可使用 `earcut` 库进行三角剖分（轻量，约 14KB）

## 六、交互流程

### 6.1 新建围栏流程

```
用户点击"新建围栏" 
  → 弹出对话框输入名称和颜色 
  → 确认后进入地图绘制模式 
  → 用户在地图上点击多个点 
  → 双击或点击"完成"结束绘制 
  → 围栏数据保存到后端 
  → 列表更新显示新围栏
```

### 6.2 拖拽照片到围栏流程

```
用户从媒体列表拖拽照片 
  → 悬停在悬浮列表的围栏项上 
  → 围栏项高亮提示 
  → 松开鼠标完成拖放 
  → 生成围栏内随机坐标（WGS-84） 
  → 调用 /api/media/set-gps 设置坐标 
  → 地图跳转到该位置并显示标记 
  → 提示"已设置到围栏 XXX 内"
```

### 6.3 编辑围栏流程

```
用户点击围栏卡片的"编辑"按钮 
  → 弹出对话框显示当前名称和颜色 
  → 修改后保存 
  → 或点击"编辑区域"按钮 
  → 地图进入编辑模式，显示可拖动顶点 
  → 用户调整顶点位置 
  → 点击"保存"按钮 
  → 更新围栏数据到后端
```

## 七、技术实现要点

### 7.1 依赖管理

- **新增依赖**：
  - `@mapbox/mapbox-gl-draw`：Mapbox 绘图插件（~100KB gzipped）
  - `earcut`：轻量三角剖分库（~14KB）
  - `uuid`：生成唯一 ID（已存在或使用浏览器 `crypto.randomUUID()`）

- **依赖分类**：确保前端依赖放在 `devDependencies`，避免 pkg 打包时误打入 exe

### 7.2 坐标系转换

- 使用项目现有的 `@shared/gps.ts` 中的转换函数：
  - `wgs84ToGcj02()`：WGS-84 转 GCJ-02（高德显示）
  - `gcj02ToWgs84()`：GCJ-02 转 WGS-84（存储）

### 7.3 并发控制

- 地图上同时只能有一个围栏处于绘制或编辑状态
- 进入绘制/编辑模式时，禁用其他围栏的点击交互
- 退出绘制/编辑模式时，恢复正常交互

### 7.4 性能优化

- 围栏数量较多时（> 50），地图上只渲染当前视口内的围栏
- 三角剖分结果可以缓存，避免每次拖拽都重新计算
- 悬浮列表使用虚拟滚动（如围栏数量 > 100）

### 7.5 错误处理

- 围栏顶点少于 3 个：提示"多边形至少需要 3 个顶点"
- 随机坐标生成失败：降级使用围栏几何中心
- 后端保存失败：提示用户并保留本地修改，允许重试
